# Kinship Lab

Six short animal classification puzzles. Pick the animal that shares a named family or genus and compare your answer with the explanation.

Open `index.html` in any modern browser. The exercise works offline, uses no external assets, and supports mouse, touch and keyboard input.

[Download the offline edition](https://github.com/soler-yang/kinship-lab/releases/latest) · [Play the daily animal mystery](https://guesstheanimalgame.com/)
